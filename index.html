Quick Start

  1. Install Python 3.10+ (tick “Add to PATH” on Windows).
  2. Download the repo ZIP or clone it.
  3. Open a terminal in the project folder and run:
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000 in your browser. Drop files there — not on this GitHub page.

Recommended extras: Ghostscript, LibreOffice, Potrace (see README). Windows: double-click run_local.bat.
